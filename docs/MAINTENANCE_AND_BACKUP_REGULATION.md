# Регламент технического сопровождения и резервного копирования ИС «Электронный учебный кабинет преподавателя и студента»

## 1. Общие положения (Раздел 8 ТЗ)
Настоящий регламент определяет порядок контроля работоспособности, резервного копирования, аварийного восстановления, анализа журналов событий и обновления веб-приложения «Электронный учебный кабинет преподавателя и студента».

- **Ответственное лицо:** Администратор учебного кабинета / ведущий преподаватель дисциплины.
- **Объекты сопровождения:**
  1. Веб-приложение ASP.NET Core 10.0 (`StudyRoom`);
  2. База данных PostgreSQL (`studyroom_db`);
  3. Защищённое файловое хранилище учебных материалов (`App_Data/Materials`).

---

## 2. Регламент и расписание профилактических работ

| Вид регламентной работы | Периодичность | Инструмент / метод проверки |
|---|---|---|
| Контроль доступности веб-приложения и службы PostgreSQL | Ежедневно перед началом занятий | Проверка `Get-Service postgresql*` и открытие главной страницы `/` |
| Резервное копирование БД и файлов лекций | Ежедневно (после окончания учебных пар) и перед каждым обновлением | Скрипт [`scripts/backup.ps1`](../scripts/backup.ps1) (`pg_dump` + архив `Materials.zip`) |
| Контроль прав доступа и аудит действий | Еженедельно | Просмотр таблицы `AuditLogs` в панели преподавателя (`/Teacher/Index`) |
| Тестовое восстановление из резервной копии | 1 раз в семестр | Скрипт [`scripts/restore.ps1`](../scripts/restore.ps1) |
| Установка обновлений и миграций схемы БД | По мере выпуска доработок | `dotnet ef database update` и перезапуск приложения |

## 3. Порядок резервного копирования и восстановления

### 3.1. Создание полной резервной копии
В состав проекта включён автоматизированный скрипт [`scripts/backup.ps1`](../scripts/backup.ps1), который сохраняет:
1. Полный SQL-дамп базы данных PostgreSQL (`studyroom_db.sql`) с помощью штатной утилиты `pg_dump.exe`;
2. ZIP-архив всех загруженных преподавателем файлов лекций (`Materials.zip` из каталога `App_Data/Materials`).

Команда запуска из PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\backup.ps1
```
Резервная копия помещается в каталог `Backups\backup_YYYYMMDD_HHMMSS\`.

### 3.2. Восстановление после сбоя
Для восстановления базы данных и каталога учебных материалов из проверенной копии выполните скрипт [`scripts/restore.ps1`](../scripts/restore.ps1), указав путь к папке резервной копии:
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\restore.ps1 -BackupFolderPath ".\Backups\backup_20261019_233000"
```

## 4. Действия при возникновении нештатных ситуаций

1. **Веб-приложение не отвечает по сети:**
   - Проверить состояние процесса `StudyRoom` / `dotnet` и правила брандмауэра Windows для TCP-порта;
   - Перезапустить приложение.
2. **Ошибка подключения к базе данных (`NpgsqlException`):**
   - Проверить статус службы PostgreSQL:
     ```powershell
     Start-Service postgresql-x64-18
     ```
   - Проверить корректность строки подключения `DefaultConnection` в `appsettings.json`.
3. **Утеря или повреждение файла учебного материала:**
   - Заменить файл через страницу редактирования лекции `/Teacher/LectureEdit?id={id}` либо восстановить архив `Materials.zip` с помощью `scripts/restore.ps1`.
