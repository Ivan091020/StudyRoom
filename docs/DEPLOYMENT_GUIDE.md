# Руководство по внедрению веб-приложения «Электронный учебный кабинет преподавателя и студента»

## 1. Подготовка компьютера преподавателя (Раздел 6.1 ТЗ)

### 1.1. Системные требования
- **Операционная система:** Windows 10 / 11 (x64) или Windows Server 2019/2022.
- **Оперативная память:** не менее 4 ГБ (рекомендуется 8 ГБ).
- **Свободное место на диске:** не менее 2 ГБ для СУБД, приложения и загружаемых учебных материалов.
- **Установленное ПО:**
  - Среда выполнения **.NET 10.0 SDK / ASP.NET Core Runtime 10.0** (`dotnet --version` -> `10.0.x`);
  - СУБД **PostgreSQL 18** (служба `postgresql-x64-18` в состоянии `Running`, порт `5432`);
  - Система контроля версий **Git**.

### 1.2. Настройка подключения к базе данных и каталога материалов
Параметры подключения задаются в конфигурационном файле [`appsettings.json`](../appsettings.json):
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=studyroom_db;Username=postgres;Password=postgres;"
  },
  "MaterialsStorage": {
    "DirectoryPath": "App_Data/Materials"
  }
}
```
- При первом запуске приложение автоматически применяет миграции Entity Framework Core (`Database.MigrateAsync()`) и создаёт каталог защищённого хранения материалов `App_Data/Materials` вне публичной папки `wwwroot`.
- Инициализатор [`DbSeeder.cs`](../Data/DbSeeder.cs) автоматически создаёт:
  - учётную запись преподавателя (`teacher` / `Teacher123!`),
  - тестовые учётные записи студентов (`student1` / `Student123!`, `student2` / `Student123!`),
  - учебную группу `ИСП-41`,
  - демонстрационную дисциплину «Внедрение и поддержка компьютерных систем», тему «Тестирование программного обеспечения», 3 последовательные лекции с материалами PDF/DOCX, контрольными вопросами 6 типов и итоговыми тестами.

## 2. Сборка и развёртывание в конфигурации Release (Раздел 6.2 ТЗ)

### 2.1. Сборка и публикация проекта
Откройте терминал PowerShell в корневом каталоге проекта `StudyRoom` и выполните:
```powershell
dotnet build -c Release
dotnet publish -c Release -o .\publish
```

### 2.2. Запуск опубликованной версии на веб-сервере Kestrel
```powershell
dotnet .\publish\StudyRoom.dll --urls "http://0.0.0.0:5050;https://0.0.0.0:5051"
```

## 3. Организация доступа студентов (Раздел 6.3 ТЗ)

### Вариант 1. Локальная работа на компьютере преподавателя
Приложение открывается в браузере по адресу:
- `http://localhost:5050` или `https://localhost:7186` (при запуске из Visual Studio / `dotnet run`).

### Вариант 2. Работа по локальной вычислительной сети (ЛВС)
1. Определите IPv4-адрес компьютера преподавателя в локальной сети:
   ```powershell
   ipconfig
   ```
   *(например, `192.168.1.100`)*.
2. Разрешите входящие подключения к порту веб-сервера Kestrel (`5050`/`5051`) в брандмауэре Windows (при этом порт СУБД PostgreSQL `5432` остаётся закрытым для внешних подключений):
   ```powershell
   New-NetFirewallRule -DisplayName "StudyRoom Web App (TCP 5050)" -Direction Inbound -LocalPort 5050 -Protocol TCP -Action Allow
   ```
3. Студенты учебного класса подключаются со своих рабочих мест через браузер по адресу `http://192.168.1.100:5050`, проходят регистрацию либо входят под выданными логинами. Прямой доступ студентов к СУБД PostgreSQL и файловой системе сервера исключён.
